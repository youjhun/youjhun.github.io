바이오및뇌공학의 여러 하위 분야를 한 번에 훑는 입문 과목이다. 세부 기술을 외우기보다 어떤 규모의 생명현상을 어떤 측정과 조작으로 다루는지를 중심으로 묶는다.

## 개념 지도

| 규모 | 핵심 질문                                           | 이어지는 주제                              |
| ---- | --------------------------------------------------- | ------------------------------------------ |
| 분자 | 유전정보와 단백질은 어떻게 만들어지고 조절되는가?   | 생화학, 유전체학, 단백질공학               |
| 세포 | 세포는 외부 신호를 어떻게 받아 상태를 바꾸는가?     | 신호전달, 세포주기, 암                     |
| 조직 | 세포 집단의 구조와 기능을 어떻게 만들고 복원하는가? | 줄기세포, 조직공학, 재생의학               |
| 개체 | 면역·신경·생리 시스템은 어떻게 상호작용하는가?      | 면역공학, 신경공학, 생리학                 |
| 계측 | 보이지 않는 생명현상을 어떤 신호로 바꾸는가?        | 바이오센서, bioinstrumentation, bioimaging |
