> [!abstract] 한눈에
> 1계 방정식은 꼴을 먼저 알아보면 풀이법이 정해진다. 분리형이면 변수를 나눠 적분하고, 선형이면 적분인자를 곱하고, 완전미분이면 퍼텐셜 함수를 찾는다. 동차형·Bernoulli·Riccati는 치환으로 앞의 꼴 가운데 하나로 바꾼다.

## 꼴을 알아보는 순서

$y' = f(x,y)$ 또는 $M\,dx + N\,dy = 0$을 받으면 다음 순서로 확인한다.

1. $f(x,y) = g(x)h(y)$로 나뉘면 분리형이다.
2. $y' + P(x)y = Q(x)$로 쓸 수 있으면 선형이다.
3. $M_y = N_x$이면 완전미분이다. 아니면 $x$나 $y$만의 적분인자를 찾는다.
4. $f$가 $y/x$만의 함수이면 동차형이다.
5. $y' + Py = Qy^n$이면 Bernoulli, $y' = P + Qy + Ry^2$이면 Riccati다.
6. $y' = f(y)$처럼 독립변수가 드러나지 않으면 자율 방정식이다. 풀기 전에 평형점과 안정성을 먼저 볼 수 있다.

| 꼴 | 판별 | 풀이 | 결과 |
| --- | --- | --- | --- |
| 분리형 | $y' = g(x)h(y)$ | $\int dy/h(y) = \int g(x)\,dx$ | 음함수 해, $h(y_0)=0$인 상수해 따로 |
| 선형 | $y' + P(x)y = Q(x)$ | $\mu = e^{\int P\,dx}$를 곱함 | $y = \mu^{-1}\left(\int \mu Q\,dx + C\right)$ |
| 완전 | $M_y = N_x$ | $F_x = M$, $F_y = N$인 $F$ | $F(x,y) = C$ |
| 적분인자 | $(M_y - N_x)/N$이 $x$만의 함수 | $\mu(x) = e^{\int (M_y - N_x)/N\,dx}$ | 곱한 뒤 완전미분으로 풂 |
| 동차형 | $y' = F(y/x)$ | $y = ux$ | $\int du/(F(u)-u) = \ln\lvert x\rvert + C$ |
| Bernoulli | $y' + Py = Qy^n$ | $u = y^{1-n}$ | $u' + (1-n)Pu = (1-n)Q$ |
| Riccati | $y' = P + Qy + Ry^2$, 한 해 $y_1$을 앎 | $y = y_1 + 1/v$ | $v' + (Q + 2Ry_1)v = -R$ |

선형식, 완전미분, 적분인자, Bernoulli의 유도는 [[first-order-linear-exact|적분인자와 완전미분방정식]]에 있다. 이 글은 공식과 예를 모아 둔다.

## 분리형

$y' = g(x)h(y)$에서 $h(y) \ne 0$인 구간을 잡아 양변을 $h(y)$로 나누고 적분한다. 나눌 때 버린 $h(y_0) = 0$인 상수해 $y = y_0$은 따로 확인한다.

예를 들어 $y' = xy^2$, $y(0) = 1$이면 $-1/y = x^2/2 + C$에서 $C = -1$이고 $y = 2/(2 - x^2)$다. 해는 $\lvert x\rvert < \sqrt2$에서만 정의되어, 계수가 매끄러워도 해가 유한한 시간에 발산할 수 있다(직접 계산한 예).

## 선형

$y' + 2y = e^{-x}$이면 $\mu = e^{2x}$를 곱해 $(e^{2x}y)' = e^{x}$이고, $y = e^{-x} + Ce^{-2x}$다(직접 계산한 예). 계수가 상수인 $y' + ay = b$의 해 $y = b/a + Ce^{-ax}$는 RC 회로, 1차 제거 모형, 뉴턴 냉각에 공통으로 나타난다.

## 동차형

$y' = F(y/x)$이면 $y = ux$로 두어 $y' = u + xu'$를 넣는다. $xu' = F(u) - u$는 분리형이다.

예를 들어 $y' = (x + y)/x = 1 + y/x$이면 $xu' = 1$에서 $u = \ln\lvert x\rvert + C$이고, $y = x\ln\lvert x\rvert + Cx$다(직접 계산한 예). 여기서 «동차»는 $y/x$의 함수라는 뜻이다. 2계 선형식의 «동차»(우변이 0)와는 다른 용어다.

## Bernoulli와 Riccati

Bernoulli 식 $y' + y = y^2$은 $n = 2$이므로 $u = y^{-1}$로 두면 $u' - u = -1$이 된다. $u = 1 + Ce^{x}$이므로 $y = 1/(1 + Ce^{x})$이고, 치환에서 빠진 $y = 0$도 해다(직접 계산한 예).

Riccati 식은 해 하나 $y_1$을 알아야 선형식으로 바뀐다. $y' = -2 - y + y^2$에는 상수해 $y_1 = 2$가 있다. $y = 2 + 1/v$를 넣으면 $v' + 3v = -1$이고 $v = Ce^{-3x} - 1/3$이므로

$$
y = 2 + \frac{1}{Ce^{-3x} - 1/3}
$$

이다(직접 계산한 예). $C = 0$이면 다른 상수해 $y = -1$이 나온다. 출발점으로 쓴 $y = 2$는 $v \to \infty$에 해당해 이 식에 직접 들어 있지 않으므로 따로 적는다.

## 자율 방정식과 위상선

$y' = f(y)$에서 $f(y^*) = 0$인 $y^*$가 평형해다. $y^*$ 근처에서 $f$의 부호를 보면 안정성을 알 수 있다.

| 평형점에서 | 근처의 흐름 | 분류 |
| --- | --- | --- |
| $f'(y^*) < 0$ | 양쪽에서 $y^*$로 다가감 | 안정(끌개) |
| $f'(y^*) > 0$ | 양쪽에서 멀어짐 | 불안정(밀개) |
| $f'(y^*) = 0$ | 한쪽은 다가가고 한쪽은 멀어질 수 있음 | 반안정이거나 고계 항으로 판정 |

로지스틱 방정식 $y' = ry(1 - y/K)$는 $y = 0$(불안정)과 $y = K$(안정)를 평형점으로 가진다. 해는

$$
y(t) = \frac{K}{1 + \dfrac{K - y_0}{y_0}e^{-rt}}
$$

이고, $y_0 > 0$이면 $K$로 다가간다. 증가 속도는 $y = K/2$에서 가장 크다.

## 대표 모형

| 모형 | 방정식 | 해 |
| --- | --- | --- |
| 지수 성장·감쇠 | $y' = ky$ | $y = y_0e^{kt}$, 반감기 $\ln 2/\lvert k\rvert$ |
| 뉴턴 냉각 | $T' = -k(T - T_m)$ | $T = T_m + (T_0 - T_m)e^{-kt}$ |
| 혼합 탱크 | $A' = r_\text{in}c_\text{in} - \dfrac{r_\text{out}}{V(t)}A$ | 선형식, $V(t) = V_0 + (r_\text{in} - r_\text{out})t$ |
| RC 회로 | $RCv' + v = v_s$ | $v = v_s + (v_0 - v_s)e^{-t/RC}$ |
| 로지스틱 | $y' = ry(1 - y/K)$ | 위의 식 |

혼합 탱크에서 들어오는 양과 나가는 양이 다르면 부피 $V(t)$가 시간에 따라 변해 계수가 상수가 아니다. 이때도 선형식이므로 적분인자로 푼다.

## 유의점

- 분리형으로 나눌 때 $h(y) = 0$인 상수해를 잃기 쉽다. 풀이 끝에 따로 확인한다.
- 해의 정의 구간은 계수의 연속 구간보다 짧을 수 있다. 비선형식은 유한한 시간에 발산하기도 한다.
- 동차형의 «동차»와 선형식의 «동차»는 서로 다른 뜻이다.
- Riccati 식을 $y = y_1 + 1/v$로 푼 일반해에는 출발점으로 쓴 $y_1$ 자신이 들어 있지 않다. $y_1$도 해 목록에 따로 적는다.
