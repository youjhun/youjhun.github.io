> [!abstract] 한눈에
> 연속시간 시스템은 덧셈기, 상수배, 적분기로 이루어진 블록 다이어그램으로 그릴 수 있고, 적분기를 연산자 $A$로 쓰면 시스템을 $A$의 다항식 비로 다룰 수 있다. 피드백 고리 하나가 만드는 임펄스 응답은 $e^{pt}u(t)$이고, $p$의 실수부가 음수이면 수렴한다. 연속시간의 적분 $A$와 기본 모드 $e^{pt}$는 이산시간의 지연 $R$과 기본 모드 $p^n$에 대응한다.

## 네 가지 표현

[[difference-equations-feedback|이산시간 시스템]]처럼 연속시간 시스템도 여러 방식으로 나타낸다. 강의 자료의 예는 잔고에 비례해 늘고 입금 속도만큼 더해지는 계좌다.

| 표현 | 예 | 쓰임 |
| --- | --- | --- |
| 말 | 잔고에 비례하는 속도와 입금 속도의 합으로 잔고가 는다 | 근거를 남긴다 |
| 미분방정식 | $\dot y(t) = x(t) + p\,y(t)$ | 짧고 정확하다 |
| 블록 다이어그램 | 덧셈기, 상수배 $p$, 적분기 | 신호가 흐르는 경로를 보인다 |
| 연산자 | $(1 - pA)Y = AX$ | 시스템을 다항식으로 다룬다 |

이산시간 블록 다이어그램의 지연이 연속시간에서는 적분기로 바뀐다. 덧셈기, 상수배, 적분기만으로 계수가 상수인 선형 미분방정식으로 기술되는 시스템을 그린다.

## 적분 연산자

연산자 $A$는 신호를 받아 모든 시각에서 그 적분값을 가지는 새 신호를 만든다.

$$
Y = AX \iff y(t) = \int_{-\infty}^{t} x(\tau)\,d\tau
$$

$A$로 쓴 식은 다항식처럼 교환, 분배, 결합 법칙을 따른다. 입력과 그 적분을 더하는 단을 두 번 이으면 $W = (1 + A)X$, $Y = (1 + A)W$이므로

$$
Y = (1 + A)^2 X = (1 + 2A + A^2)X
$$

가 된다. 시간 영역으로 쓰면 이중 적분이 들어간 긴 식이 되지만, 연산자로 쓰면 블록 수준에서 정리된다.

같은 방법으로 두 블록 다이어그램이 같은 시스템인지 확인한다. 피드백 계수 $-0.7$과 $-0.9$인 1차 단을 이으면 $(1 + 0.7A)(1 + 0.9A)Y = A^2X$, 곧 $(1 + 1.6A + 0.63A^2)Y = A^2X$다. 적분기 두 개와 피드백 계수 $k_1$, $k_2$로 만든 2차 구조는 $(1 - k_1A - k_2A^2)Y = A^2X$이므로 $k_1 = -1.6$, $k_2 = -0.63$이면 두 시스템이 같다.

## 단위 임펄스와 단위 계단

이산시간의 $\delta[n]$에 해당하는 연속시간 신호로 $t = 0$에서만 1이고 나머지에서 0인 함수를 생각할 수 있다. 이 함수의 적분은 0이므로, 넓이가 1이고 폭이 0으로 줄어드는 펄스의 극한을 쓴다.

$$
\delta(t) = \lim_{\epsilon \to 0} p_\epsilon(t), \qquad p_\epsilon(t) = \begin{cases} \frac{1}{2\epsilon} & \vert t\vert < \epsilon \\ 0 & \text{그 밖} \end{cases}
$$

**단위 임펄스** $\delta(t)$는 $t = 0$ 밖에서 0이면서 전체 적분이 1이다. 두 성질은 $\delta(t)$를 펄스의 극한으로 보면 함께 성립한다. $\delta(t)$를 적분하면 **단위 계단** $u(t)$가 된다.

$$
u(t) = \int_{-\infty}^{t}\delta(\lambda)\,d\lambda = \begin{cases} 1 & t \ge 0 \\ 0 & \text{그 밖} \end{cases}
$$

$A\delta = u$이고, 한 번 더 적분하면 $A^2\delta = t\,u(t)$다. 피드백이 없는 시스템은 연산자 식을 그대로 계산하면 임펄스 응답이 나온다. 앞의 $(1 + 2A + A^2)$ 시스템의 임펄스 응답은 $\delta(t) + 2u(t) + t\,u(t)$다.

## 피드백과 기본 모드

입력과 출력의 $p$배를 더해 적분하는 시스템 $\dot y = x + py$의 임펄스 응답을 두 가지로 구한다.

첫째 방법으로 미분방정식에 $y(t) = Ce^{\alpha t}u(t)$를 넣는다. $\dot y = \alpha Ce^{\alpha t}u(t) + C\delta(t)$이므로 양변을 맞추면 $\alpha = p$, $C = 1$이다.

둘째 방법은 연산자를 쓴다. $Y = A(X + pY)$에서

$$
\frac{Y}{X} = \frac{A}{1 - pA} = A(1 + pA + p^2A^2 + p^3A^3 + \cdots)
$$

이고, 각 항에 $\delta(t)$를 넣으면 $A^{k+1}\delta = \frac{t^k}{k!}u(t)$이므로

$$
h(t) = \left(1 + pt + \frac{p^2t^2}{2} + \frac{p^3t^3}{6} + \cdots\right)u(t) = e^{pt}u(t)
$$

가 된다. 급수의 각 항은 신호가 피드백 고리를 한 바퀴 더 돈 기여다. 연속시간에서는 한 바퀴마다 적분이 하나 늘고, 이산시간에서는 한 바퀴마다 출력에 표본이 하나 늘어 $p^n u[n]$이 된다.

$e^{pt}$를 이 시스템의 **기본 모드**라 한다. $p < 0$이면 수렴하고 $p > 0$이면 발산한다(그림 1 왼쪽). $p$가 복소수이면 실수부의 부호가 이를 정한다. 수렴하는 극점은 복소평면의 왼쪽 반평면에 있고, 이산시간에서 단위원 안쪽에 대응한다.

| | 연속시간 | 이산시간 |
| --- | --- | --- |
| 방정식 | $\dot y(t) = x(t) + py(t)$ | $y[n] = x[n] + py[n-1]$ |
| 시스템 함수식 | $\frac{A}{1 - pA}$ | $\frac{1}{1 - pR}$ |
| 임펄스 응답 | $e^{pt}u(t)$ | $p^n u[n]$ |
| 수렴 조건 | $\operatorname{Re} p < 0$ | $\vert p\vert < 1$ |

2차 시스템은 분모를 인수분해해 극점마다 판정한다. $\frac{1}{1 + 2A + \frac{3}{4}A^2} = \frac{1}{(1 + \frac{1}{2}A)(1 + \frac{3}{2}A)}$은 두 극점 $-\frac12$, $-\frac32$가 모두 왼쪽 반평면에 있어 수렴한다. $\frac{1}{1 - \frac14A^2}$은 극점 $\pm\frac12$ 가운데 하나가 오른쪽에 있어 발산한다.

이산시간에서 같은 계수의 $\frac{1}{1 - \frac14R^2}$은 극점 $\pm\frac12$가 모두 단위원 안에 있어 수렴한다. 반대로 $\frac{1}{1 + 2R + \frac34R^2}$은 극점 $-\frac12$, $-\frac32$ 가운데 $-\frac32$가 단위원 밖에 있어 발산한다. 같은 계수라도 연속시간과 이산시간의 판정 결과가 다를 수 있다.

## 질량-스프링 시스템

질량 $M$이 스프링 상수 $K$인 스프링으로 위치 $x(t)$에 연결되어 있으면 $K(x - y) = M\ddot y$다. 적분기 두 개로 그리면

$$
\frac{Y}{X} = \frac{\frac{K}{M}A^2}{1 + \frac{K}{M}A^2}
$$

이다. 분모를 $(1 - p_0A)(1 - p_1A) = 1 - (p_0 + p_1)A + p_0p_1A^2$과 맞추면 극점의 합은 0, 곱은 $K/M$이므로 $p_{0,1} = \pm j\omega_0$, $\omega_0 = \sqrt{K/M}$이다. $A$에 $1/s$를 넣어 $\frac{K/M}{s^2 + K/M}$의 분모 근을 찾아도 같은 극점이 나온다.

두 기본 모드 $e^{\pm j\omega_0 t}$는 복소수다. 부분분수로 나누면

$$
\frac{Y}{X} = \frac{\omega_0}{2j}\,\frac{A}{1 - j\omega_0A} - \frac{\omega_0}{2j}\,\frac{A}{1 + j\omega_0A}
$$

이고, 두 모드와 계수가 각각 켤레 복소수라 합이 실수가 된다.

$$
h(t) = \frac{\omega_0}{2j}e^{j\omega_0 t} - \frac{\omega_0}{2j}e^{-j\omega_0 t} = \omega_0\sin\omega_0 t, \qquad t > 0
$$

시스템 함수식을 $A$의 급수 $\omega_0^2A^2 - \omega_0^4A^4 + \omega_0^6A^6 - \cdots$로 전개해도 같은 결과가 나온다. 임펄스를 넣으면 $\omega_0^2 t - \omega_0^4\frac{t^3}{3!} + \omega_0^6\frac{t^5}{5!} - \cdots$이고, 이는 $\omega_0\sin\omega_0 t$의 테일러 급수다. 항을 늘릴수록 부분합이 더 긴 구간에서 사인 곡선과 겹친다(그림 1 오른쪽).

## 유의점

- $A$는 $-\infty$부터 적분하므로 신호가 $t \to -\infty$에서 0이라고 가정한다. 초기 조건이 있는 문제는 따로 다뤄야 한다(강의 자료 밖의 설명).
- 연속시간의 수렴 조건은 극점의 실수부 부호이고, 이산시간의 조건은 극점의 크기다. 같은 계수의 다항식이라도 $A$와 $R$에서 결론이 다를 수 있다.
- $\delta(t)$는 보통의 함수로 정의되지 않는다. 넓이가 1인 펄스의 극한으로 보고, 적분 안에서 쓰는 대상으로 다룬다(강의 자료 밖의 설명).
- 순허수 극점의 모드는 수렴도 발산도 하지 않는다. 질량-스프링 시스템의 임펄스 응답 $\omega_0\sin\omega_0 t$는 크기가 줄지 않고 계속 진동한다.
