> [!abstract] 한눈에
> 사인파는 이득·필터 응답을 분리해 확인하기 좋지만 실제 EMG의 불규칙한 크기를 대신하지 못한다. 공개 기록을 PWL 전압원으로 재생해 [[emg-afe-kicad|회로]]의 활동 검출을 시험했다. 원 자료의 단위와 선행 필터를 보존하고, 보정에 사용한 시행과 성능 평가용 시행을 분리해야 한다.

## 직접 변환할 목표

지금까지는 사인파와 준비된 EMG 입력 파일로 회로가 어떻게 반응하는지 확인했다. 입력만 바꾸어도 결과가 달라지는 것을 봤는데, 정작 그 입력 파일이 원본 데이터에서 어떻게 만들어지는지도 직접 확인할 필요가 있다.

이번 목표는 EMG 원본을 읽고, 시간과 전압으로 바꾼 뒤, KiCad에서 같은 파형을 재생하는 것이다. 회로의 저항값과 판정 문턱은 그대로 둔다. 먼저 파일을 올바르게 변환했는지 확인하고, 그다음 회로가 신호를 잘 구분하는지 살펴본다.

## 변환 실습의 순서

Trial 2의 주먹 기록에서 F1 채널 하나를 먼저 사용한다. 기존 패키지의 raw 폴더에는 원본 `.hea`와 `.dat`가 있으므로, 만들어진 CSV나 lib 대신 두 원본 파일에서 시작한다. 아래는 직접 구현할 순서이며, 새 변환 코드의 실행 결과는 아직 추가하지 않았다.

| 순서 | 할 일 | 확인할 결과 |
| --- | --- | --- |
| 1 | 헤더의 첫 줄과 F1 설명 읽기 | 채널 수, 표본률, 표본 수, 저장 형식과 단위 |
| 2 | 바이너리를 정수 배열로 읽고 F1 선택 | 배열 크기와 첫 샘플이 헤더와 일치 |
| 3 | 샘플 번호에서 시간축 만들기 | 기록 길이와 샘플 간격이 헤더와 일치 |
| 4 | 헤더 계수로 정수를 전압으로 환산 | mV와 V를 구분한 원본 EMG 파형 |
| 5 | 시간과 전압을 PWL 파일로 작성 | 1.650 V 기준을 더한 KiCad 입력 |
| 6 | 입력 소스만 재생해 원본과 비교 | 같은 시각의 값과 파형이 일치 |
| 7 | 기존 회로에 연결해 휴식·주먹 비교 | 고정한 문턱에서의 검출 결과 |

한 단계씩 값을 확인하며 진행한다. 그래프가 작거나 회로가 켜지지 않는다는 이유로 입력 진폭을 임의로 키우지 않는다. 어떤 변환을 했는지 설명하고, 원본과 재생값이 일치하는지 확인할 수 있어야 다음 단계로 넘어간다.

아래의 환산식·PWL 예시·기존 재현 코드는 비교 자료로 남긴다. 직접 작성한 코드와 확인한 값은 구현이 끝난 단계부터 이 기록에 보탠다.

## 기록과 단위

| 항목 | 사용한 값 |
| --- | --- |
| 데이터 | GRABMyo v1.1.0, PhysioNet |
| 사람·날짜 구분 | Participant 1, Session 1 |
| 시행·채널 | Trial 1, F1 |
| 주먹 | `session1_participant1_gesture16_trial1` |
| 휴식 | `session1_participant1_gesture17_trial1` |
| 길이·표본률 | 각 5 s, 2048 Hz, 10240 samples |
| 원본 형식 | WFDB `.hea`와 `.dat`, format 16 |
| 단위 | 헤더 환산 후 mV, 이후 V로 변환 |
| 라이선스 | CC BY 4.0, 원저자·DOI·변경 내역 명시 |

논문에서의 유효 전극 채널 28개와 파일에 저장된 32개 열을 혼동하지 않는다. 파일의 열 수·채널 이름은 헤더를 기준으로 읽고 그중 F1만 선택했다. Participant 1은 데이터의 익명 식별자다.

헤더에서 F1의 ADC gain과 baseline을 읽어 다음과 같이 환산한다.

$$
e_{mV}[n]=\frac{d[n]-baseline}{adc\_gain},\qquad
e_V[n]=10^{-3}e_{mV}[n],\qquad t_n=\frac n{2048}.
$$

이 gain은 저장된 정수와 물리 단위 사이의 변환 계수다. 논문에 기술된 장비 증폭률 500으로 다시 나누지 않는다. 환산 후 파형별 최대값을 1로 맞추는 정규화도 하지 않았다. 휴식과 주먹의 실제 크기 차이가 시험에 남아 있어야 하기 때문이다.

| F1 원본 환산값 | 휴식 | 주먹 |
| --- | --- | --- |
| 평균 | 0.00140 µV | −0.02280 µV |
| RMS | 13.67980 µV | 43.90528 µV |
| MIN | −69.86726 µV | −472.88743 µV |
| MAX | 46.19209 µV | 205.84865 µV |
| 평균 절댓값 | 10.66326 µV | 30.11290 µV |

이는 전체 5초 입력 기록의 통계다. 회로 출력의 0.5–2초 MIN·AVG·MAX와 분석 구간·단위가 다르다. 양·음이 상쇄되는 작은 평균과 큰 RMS가 함께 존재할 수 있다.

원 논문은 수집 사슬의 10–500 Hz 대역통과와 60 Hz notch를 기술한다. 이번 변환에서 추가 필터링·평균 제거를 하지 않았다는 설명은 원 자료가 미가공 전극 전압이라는 의미가 아니다. 실제 전극 임피던스·DC·공통모드 검증에는 별도 입력 모형이 필요하다.

## 재생 파일의 구조

`.lib`는 가상 부품의 회로·모델을 정의하는 텍스트 파일이다. 파일 확장자가 신호를 생성하는 것은 아니며, 내부의 독립 전압원과 PWL 표가 시간별 전압을 지정한다. 원시 샘플 전체를 수동 입력하는 대신 스크립트로 작성한다.

```spice
* 구조 예시이며 아래 표본값은 설명용이다.
.SUBCKT EMG_REST_F1 P N
VREPLAY P N PWL(
+ 0.000000000 1.650010000
+ 0.000488281 1.649995000
+ 0.000976562 1.650003000
+ )
.ENDS EMG_REST_F1
```

PWL의 표본 사이 전압은 선형 보간된다. 여러 줄을 이을 때 각 후속 줄의 `+`를 유지하며 닫는 괄호도 `+ )`로 연결한다. 실제 생성 파일은 10240개 샘플을 포함하고 마지막 표본을 5초까지 유지한다.

원 논문의 수집은 monopolar sEMG다. F1 한 채널을 이 회로의 차동 시험 입력으로 취급하는 것이며, 원 실험의 두 전극 원전압을 복원한 것이 아니다.

입력 연결은 다음과 같다.

| 대상 | 연결·설정 |
| --- | --- |
| 모델 P | INA333 IN+, 물리 핀 3 |
| 모델 N | GND |
| 반대 입력 | INA333 IN−, 물리 핀 2에 이상적 DC 1.650 V |
| 재생 전압 | $1.650+e_V(t)$ V |
| 차동 입력 | $(1.650+e_V)-1.650=e_V$ |
| REF | 측정된 VBIAS, 약 1.64 V |

전압원 심볼을 사용하더라도 외부 SUBCKT를 지정하면 넷리스트 호출은 `X...`로 생성된다. `Sim.Device=SUBCKT`, `Sim.Library=models/emg_F1_replay.lib`, `Sim.Name=EMG_REST_F1` 또는 `EMG_HAND_CLOSE_F1`, `Sim.Pins=1=P 2=N`을 대조한다. 파일 경로와 모델 이름, 패키지 핀 번호와 모델 단자 순서는 서로 다른 항목이다.

재생 전압 1.65 V와 회로 VBIAS 약 1.64 V는 같지 않아도 된다. 두 INA 입력의 공통모드가 1.65 V이고 출력 기준이 VBIAS인 구성이다. 한 기록을 두 입력에 똑같이 넣으면 차동 신호가 상쇄되므로 이 시험의 연결과 다르다.

## 표본 간격과 계산 간격

$1/2048$ s는 약 488.281 µs다. 이는 원 데이터가 새로운 샘플을 제공하는 시간 간격이다. TRAN의 solver는 회로 오차를 제어하기 위해 그 사이에도 계산할 수 있고, 그때 입력은 원 샘플 사이의 PWL 보간값이다.

1 kHz 사인파·다이오드 전환을 검토할 때 최대 계산 간격 10 µs를 초기 설정으로 사용했다. 5초 실행은 계산량이 크므로 필요한 시간 구간을 선택하되, 간격을 줄인 실행에서 관찰 결과가 유지되는지 비교한다. 원 데이터 표본률보다 촘촘히 계산한다고 기록되지 않은 원 신호의 고주파 정보가 복구되지는 않는다.

## OP와 TRAN

`No job (tran, ac, op etc.) defined`는 실행할 분석이 등록되지 않았다는 경고다. 실제 원인 판별에는 선택한 분석, 생성 넷리스트, 앞선 오류 로그를 함께 확인해야 한다. 이 실습의 넷리스트에는 `.op`가 있었으므로 경고만 보고 OP 누락으로 결론 내리지 않았다.

초기 모델 시험에서는 gmin·source stepping 실패와 transient OP 전환을 관찰했다. 내부 MID와 출력이 예상과 달랐고, 초기 OP를 건너뛰는 TRAN에서 시간을 흘린 뒤 예상 이득이 나타났다. 이때 사용한 `Use initial conditions`는 OP를 생략하는 설정으로 기록하며, 모든 모델 수렴 문제의 해결법으로 일반화하지 않는다.

OP에는 조절할 시간 좌표가 없다. 1초 뒤 값을 보고 싶다면 TRAN의 1초 지점을 읽는다. OP 오버레이의 숫자를 TRAN 마지막 값이라고 해석하지 않고 초기 과도와 안정된 구간을 나누어 확인한다.

## 측정 명령과 표시

커서는 특정 시각의 값을 확인하는 데 쓰고, 범위·평균은 측정 패널로 계산한다. 측정 패널의 빈 행마다 명령 하나를 입력한다. 여러 측정 명령을 한 셀에 이어 붙이면 하나의 유효한 측정으로 해석되지 않는다.

```text
MIN V(/EMG_ENV_BUF) FROM=0.5 TO=2
MAX V(/EMG_ENV_BUF) FROM=0.5 TO=2
AVG V(/EMG_ENV_BUF) FROM=0.5 TO=2
PP V(/EMG_ENV_BUF) FROM=0.5 TO=2
```

| 지표 | 해석 | 주의 |
| --- | --- | --- |
| MIN·MAX | 구간의 최저·최고 전압 | 시작 과도와 클리핑에 민감 |
| AVG | 구간의 시간 평균 | DC 바이어스를 포함 |
| PP | MAX−MIN | 사인파에서 진폭의 두 배, DC에 불변 |
| RMS | 제곱 평균의 제곱근 | DC가 있으면 그 크기도 포함 |
| 중심 근사 | (MAX+MIN)/2 | 대칭 사인파에 적합, 일반 평균과 다름 |

초기 포함 MIN=−5.85975 mV, MAX=2.71279 V, AVG=1.62114 V로 보고된 예가 있었다. 전체 실행의 MIN에는 시작 조건이 들어갈 수 있으므로 안정 구간의 하단 전압으로 사용하지 않는다. 사인파 AVG도 정수 주기 또는 충분한 구간을 사용하고 분석 구간을 함께 기록한다.

측정값을 우클릭해 Format Value에서 유효숫자를 조정했다. 실습의 `6~V`는 6자리 유효숫자와 전압의 자동 접두사 표시 설정이다. `1.64 V`로만 보이던 수 mV 차이를 `1.64027 V`처럼 읽게 해 주지만 계산 자체의 정확도를 높이는 설정은 아니다.

화면을 확대해도 기본 측정 범위가 자동으로 확대 구간에 제한되지는 않는다. FROM·TO를 명시한다. File → Export Current Plot as CSV로 파형을 보존하고, 이 실습 환경의 세미콜론 구분자와 단위를 확인한다. workbook은 설정을 저장하며 실행 결과 전체를 대체하지 않는다.

다음 명령으로 출력의 교차 시각에서 입력 문턱을 읽을 수 있다. 두 명령의 1.65 V는 ACTIVITY 출력의 전환 중간값이며 입력 판정 문턱 1.642 V와 다르다. 사용한 KiCad/ngspice 버전에서 측정 구문이 지원되는지 확인하고, 불가하면 CSV 교차를 계산한다.

```text
FIND V(/EMG_ENV_BUF) WHEN V(/ACTIVITY)=1.65 RISE=1
FIND V(/EMG_ENV_BUF) WHEN V(/ACTIVITY)=1.65 FALL=1
```

## 사인파에서 공개 기록으로

사인파 시험에서는 크기와 주파수를 알고 있으므로 예상값을 먼저 계산할 수 있다. 진폭을 0.2 mV→1 mV→0.2 mV로 바꾸어 평활과 판정의 동작을 확인한 behavioral 입력은 다음과 같다.

```text
1.650 + (time < 0.5 ? 0.0002 : (time < 1.0 ? 0.001 : 0.0002))*sin(6.283185307*1000*time)
```

이는 behavioral 전압원의 식 칸에 넣는 예이며 `.lib` 전체가 아니다. 실제 EMG 기록은 같은 1 mV 진폭의 사인파보다 작고 비정상적이므로 이때 정한 판정 문턱을 그대로 쓰지 않았다.

초기 판정은 V4=1.72 V, R11=10 kΩ, R12=820 kΩ이었다. ON 약 1.741 V에 비해 실제 주먹의 ENV_BUF MAX는 1.67007 V여서 켜지지 않았다. 평균 차이 9.22 mV와 겹치지 않은 관측 범위를 확인한 뒤 V4=1.642 V, R11=1 kΩ, R12=3.3 MΩ으로 변경했다.

## 한 실행의 전환 입력

기존 두 `.SUBCKT` 정의 뒤에 아래를 추가했다. 앞선 PWL과 `.ENDS`가 정상적으로 닫혀 있어야 한다.

```spice
.SUBCKT EMG_REST_HAND_REST P N
XREST REST_NODE N EMG_REST_F1
XHAND HAND_NODE N EMG_HAND_CLOSE_F1
BSELECT P N V={time < 0.5 ? V(REST_NODE,N) : (time < 2.5 ? V(HAND_NODE,N) : V(REST_NODE,N))}
.ENDS EMG_REST_HAND_REST
```

| 시각 | 입력 선택 | 주먹 원본의 시간 |
| --- | --- | --- |
| 0–0.5 s | REST | 사용하지 않음 |
| 0.5–2.5 s | HAND CLOSE | 원본 0.5–2.5 s |
| 2.5–5 s | REST | 사용하지 않음 |

두 기록은 시간 0부터 동시에 재생되며 선택만 바뀐다. 주먹 파형을 0.5초에 처음부터 재생하는 코드가 아니다. 두 기록을 자연스럽게 이어 붙인 연속 생리 신호도 아니므로 전환 경계의 스텝·필터 과도를 별도로 해석한다.

TRAN이 2초에서 끝나면 휴식 복귀를 볼 수 없다. 종료 시간을 5초로 늘린 실행에서 OFF–ON–OFF를 확인했다. 정밀한 검출 지연은 인위적 선택 시각과의 기능상 지연으로만 계산할 수 있으며, 실제 근육 수축 onset 지연과 같지 않다.

## 라이브러리 갱신 문제

새 모델을 목록에서 선택했지만 실행 시 base model을 찾지 못하는 오류가 있었다. 기존 `EMG_HAND_CLOSE_F1`은 실행됐고 Sim.Library·Sim.Name·Sim.Pins 화면은 정상이었다. 같은 내용을 `emg_F1_replay_v2.lib`로 복사해 다시 선택하자 실행됐다.

관찰은 파일 갱신·캐시 영향과 부합하지만 KiCad 내부의 정확한 원인을 추적하지는 않았다. 오류 문구의 한국어 배치를 근거로 파일·모델을 바꾸라고 했던 진단은 취소했다. 문제 재발 시 파일 저장, 모델 속성 확인, simulator 재열기, 새 파일명 비교, 전체 오류 로그 확인 순으로 원인을 좁힌다.

## 재현 코드

저장소의 `scripts/emg_replay.py`는 지정된 두 WFDB 기록의 길이·시작값·체크섬·SHA-256을 확인하고 CSV와 세 재생 모델을 만든다. 기본 입력은 공식 PhysioNet 파일이며 기존 raw 디렉터리를 지정하면 다운로드하지 않고 사용할 수 있다. 출력 경로는 사이트의 content 밖에 둔다.

```bash
python3 scripts/emg_replay.py --output /tmp/emg-replay
# 원본 파일이 이미 있을 때
python3 scripts/emg_replay.py --raw-dir /path/to/raw --output /tmp/emg-replay
```

스크립트는 원본의 전처리를 되돌리지 않고 다른 사람·시행으로 확장하거나 입력을 자동 정규화하지 않는다. 이 코드의 입력 표본·생성 PWL 검증과 사용자의 전체 회로 실행을 구분한다.

## 후속 검증

1. 현재 부품값·VOFF·문턱·solver·분석 구간과 출력 CSV를 저장한다.
2. 문턱을 고정하고 같은 사람의 다른 trial에서 휴식 오검출과 주먹 미검출을 평가한다.
3. 다른 session·participant로 확장하고, 보정이 필요한 단위와 일반화 범위를 정의한다.
4. 짧은 잡음·움직임·공통모드·전극 DC·입력 크기 변화를 별도 합성 입력으로 시험한다.
5. 실제 부품 모델로 교체하고 오프셋·저항 공차·기준전압 변동에 대한 문턱 여유를 계산한다.

참 상태의 연속 라벨이 없으면 이벤트 onset 정확도를 평가할 수 없다. 시행 수준의 판정에서는 켜져 있는 시간 비율 등을 정의할 수 있지만 1 ms마다의 샘플을 독립 시험으로 세어 신뢰도를 부풀리지 않는다. 문턱을 정한 기록에서의 성공은 보정 결과로 기록하고 새 기록을 평가에 사용한다.

## 유의점

- `1u`는 1 µ 단위이며, `100n`과 구분한다. SPICE의 `m`은 milli이고 mega는 `Meg`로 쓴다.
- 데이터의 µV, 전압원의 V, 화면의 자동 mV 접두사를 환산 없이 섞지 않는다.
- 데이터는 원래 필터링된 물리 단위 기록이며 새 회로의 전극 측정 성능을 보증하지 않는다.
- 표의 MIN·MAX가 겹치지 않았어도 다른 구간·시행에서 같은 분리가 유지된다고 보장할 수 없다.
- C3 1/2 µF와 VOFF 설정이 다른 실행의 표를 같은 조건으로 합치지 않는다.
